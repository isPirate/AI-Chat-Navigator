# 아이콘 파일 설명

이 디렉토리에는 다음 크기의 아이콘 파일이 필요합니다:

- icon16.png - 16x16 픽셀
- icon48.png - 48x48 픽셀
- icon128.png - 128x128 픽셀

## 임시 방안

공식 아이콘을 추가하기 전에 다음 방법을 사용할 수 있습니다:

1. 웹에서 무료 아이콘 다운로드
2. 다음 온라인 도구를 사용하여 아이콘 생성:
   - https://www.favicon-generator.org/
   - https://realfavicongenerator.net/

3. 또는 단색 플레이스홀더 이미지 사용 (모든 이미지 편집기로 생성 가능)

## 추천사항

채팅/대화 관련 아이콘 사용을 권장하며, 스타일 제안:
- 심플한 말풍선 아이콘
- 그라데이션 보라색 또는 파란색
- 플랫 디자인(Flat Design)
