# AI 채팅 네비게이터

브라우저 확장 프로그램으로 ChatGPT 페이지에서 대화 기록을 빠르게 탐색하고 위치를 찾을 수 있도록 도와줍니다.

## 기능 특징

- ✅ 사용자 메시지만 기록 (AI 응답은 기록하지 않음)
- 사이드바 네비게이션 패널에 번호와 메시지 요약 표시
- 어떤 사용자 입력이든 빠르게 위치 찾기
- 대화 내용 검색 및 필터링
- 단축키 지원
- 대화 전환 자동 감지 및 초기화
- 데이터 영구 저장

## 설치 방법

### 개발 모드 설치

1. 이 프로젝트를 클론하거나 다운로드
2. Chrome 브라우저에서 `chrome://extensions/` 접속
3. 우측 상단의 '개발자 모드' 활성화
4. '압축 해제된 확장 프로그램 로드' 클릭
5. 프로젝트 루트 디렉토리 선택
6. 확장 프로그램 설치 완료

## 사용 방법

### 기본 사용

1. [ChatGPT](https://chat.openai.com/) 접속
2. 확장 프로그램이 자동으로 대화 기록
3. 우측 네비게이션 바에서 모든 대화 기록 확인
4. 원하는 메시지 클릭 시 해당 위치로 바로 이동

### 단축키

- `Alt + N`: 네비게이션 바 표시/숨기기 전환
- `Alt + S`: 검색창에 포커스

### 검색 기능

네비게이션 바의 검색창에 키워드 입력 시 대화 내용을 실시간으로 필터링합니다.

## 기술 스택

- **Manifest V3**: 최신 Chrome 확장 API
- **Vanilla JavaScript**: 프레임워크 없이 순수 JavaScript 사용
- **Chrome Storage API**: 데이터 영구 저장
- **MutationObserver**: DOM 변화 감지

## 프로젝트 구조

```
ai-chat-navigator/
├── manifest.json              # 확장 프로그램 설정 파일
├── src/
│   ├── content/
│   │   ├── index.js          # 주입 스크립트
│   │   └── style.css         # 주입 스타일
│   ├── background/
│   │   └── index.js          # 백그라운드 서비스
│   ├── popup/
│   │   ├── index.html        # 팝업 페이지
│   │   ├── style.css         # 팝업 페이지 스타일
│   │   └── index.js          # 팝업 페이지 로직
│   └── utils/
│       └── storage.js        # 저장 유틸리티 (구현 예정)
└── icons/                    # 아이콘 파일 (추가 예정)
```

## 자주 묻는 질문

### 확장 프로그램이 작동하지 않나요?

1. ChatGPT 페이지에서 사용 중인지 확인
2. 페이지 새로고침 후 재시도
3. 브라우저 콘솔에서 오류 확인

### 데이터를 어떻게 지우나요?

확장 프로그램 아이콘 클릭 후 팝업 창에서 '데이터 지우기' 버튼을 누르세요.
