# 图标文件说明

此目录需要放置以下尺寸的图标文件：

- icon16.png - 16x16 像素
- icon48.png - 48x48 像素
- icon128.png - 128x128 像素

## 临时方案

在添加正式图标之前，你可以：

1. 从网上下载免费图标
2. 使用以下在线工具生成图标：
   - https://www.favicon-generator.org/
   - https://realfavicongenerator.net/

3. 或者使用纯色占位图（任何图像编辑器创建）

## 推荐

使用聊天/对话相关的图标，样式建议：
- 简洁的对话气泡图标
- 渐变紫色或蓝色
- 扁平化设计
